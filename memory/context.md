Project Overview
AMD Options Swing Trading ML Pipeline — a 4-script system that supplements a Webull chart-based strategy for AMD 6-12 month call options with ML-derived entry signals.

Pipeline Architecture
Scripts run sequentially. Phase 1 must run first to generate the CSV that all downstream scripts depend on.

Script	Purpose	Output
entry_phase1.py	Fetch OHLCV, compute 30+ indicators	data/{ticker}_indicators.csv, data/{ticker}_dashboard.png
entry_phase2.py	Direction ML model (≥5% gain in 15d?)	data/{ticker}_ml_features.csv, data/{ticker}_ml_results.png
entry_phase3.py	IV expansion ML model (HV ≥10% higher in 10d?)	data/{ticker}_phase3_features.csv, data/{ticker}_phase3_results.png
entry_signal.py	Combines both models → single recommendation	Console output only
Primary daily-use script: entry_signal.py
